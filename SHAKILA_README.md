# Proyecto SQL - Base de Datos Shakila
## Objetivo
>Resolución de ejercicios SQL utilizando la base de datos Shakila en PostgreSQL mediante DBeaver.

Durante el proyecto se trabajó con:
- Consultas SQL.
- Relaciones entre tablas.
- JOINs.
- Funciones de agregación.
- Subconsultas.
- Vistas y tablas temporales.
## Herramientas utilizadas
- PostgreSQL.
- DBeaver.
- GitHub.
## Importación de la base de datos
**1. Crear la base de datos.**

En DBeaver : 
Create → Database

Nombre utilizado: Shakila

**2. Ejecutar el archivo SQL.**

Abrir: SQL Editor → New SQL Script

Importar el archivo proporcionado y ejecutarlo con: Ctrl + Enter

## Esquema principal de la BBDD
